# RSS Clima – Extremo Sul da Bahia

Este projeto gera um feed RSS com a previsão atual do tempo para 9 cidades da Bahia, atualizado em tempo real com base na API do OpenWeatherMap.

## Cidades Atendidas

- Itamaraju
- Prado
- Teixeira de Freitas
- Alcobaça
- Caravelas
- Itabela
- Itabatã
- Mucuri
- Nova Viçosa
## Endereço do Feed

Após publicar no Render, o feed estará disponível em:

```
https://rss-clima.onrender.com/clima/
```
